Sobre mí

Soy Oseas Pozo, Ingeniero de Software proactivo y orientado a resultados con experiencia sólida en desarrollo Full-Stack y mantenimiento de sistemas empresariales. Me especializo en el ecosistema .NET (C#), React y el diseño de arquitecturas escalables basadas en Clean Architecture, Domain-Driven Design (DDD) y CQRS.

Cuento con historial comprobado reduciendo tiempos de respuesta de sistemas críticos hasta en un 30%, asegurando aplicaciones web contra vulnerabilidades y automatizando flujos de datos a escala. Mi compromiso es entregar código limpio, seguro y resiliente que impulse el crecimiento organizacional.

OrderFlow — Catálogos & Procesamiento Resiliente de Pedidos

✦ Repositorio Oficial

Sistema backend de alta resiliencia con persistencia políglota: MongoDB para catálogo flexible y SQL Server para transacciones de órdenes con garantía ACID. Diseñado bajo Domain-Driven Design (DDD) con publicación de eventos asíncronos procesados por servicios worker dedicados. Contenerizado con Docker, aprovisionado con Terraform en Azure (Azure Key Vault, App Insights) y automatizado con CI/CD en GitHub Actions.
